# Nihongo-notes
Nihongo Notes is a beginner-focused Japanese learning platform for N5 learners that combines structured lessons with an AI-powered tutor built using the Gemini API. It offers script practice, vocabulary, grammar, and interactive writing exercises, alongside guided AI conversations to make learning Japanese more accessible and engaging.

#✨ Features
Frontend Learning Modules
Hiragana, Katakana & Kanji
Stroke practice using an on-screen canvas
Mnemonics and audio pronunciation
Vocabulary & Grammar
Beginner-friendly explanations and examples
Practice Scripts
Simple reading and usage exercises
Dashboard
Central hub to access learning sections and saved notes

#🤖 AI Japanese Tutor
Built using Google Gemini (via AI Studio)
Provides:
Conversational practice
Grammar explanations
Pronunciation guidance
Gamified learning interactions
Accessible directly from the Home/Index page

#🛠️ Tech Stack
HTML
CSS
JavaScript
Google Gemini API (AI Studio)
Canvas API
Web Audio API
LocalStorage

#🚀 How It Works
Users explore structured learning content through the website.
Writing practice is done directly on the screen using canvas-based stroke input.
The AI tutor opens via an AI Studio link and assists with explanations, conversation, and practice.
Notes and progress are managed through the dashboard interface.

#🧠 Target Audience
1-Absolute beginners in Japanese
2-JLPT N5 learners
3-Self-learners who want guided practice without overwhelming content
